The Ponytail Decision Ladder

How DevFlow evaluates technical solutions before writing code or adding dependencies.

Tier 1

Strict Relevance

Verify that the feature is explicitly requested and essential. If unneeded, eliminate it (YAGNI).

Tier 2

Internal Reuse

Check for existing helper functions, types, or components already present in the codebase.

Tier 3

Standard Library Built-ins

Use language standard library (e.g., fetch, URL, crypto, Intl) instead of external packages.

Tier 4

Native Platform Capabilities

Leverage semantic HTML5 tags (dialog, details) and modern CSS (Grid, Flexbox) before JS scripts.

Tier 5

Existing Installed Dependencies

If standard library cannot fulfill the requirement, use packages already declared in package.json.

Tier 6

Small Custom Utility

Write a focused 10-30 line function rather than importing a large single-purpose dependency.

Tier 7

New External Dependency

Add a new external dependency only when manual implementation incurs high security or complexity risks.
